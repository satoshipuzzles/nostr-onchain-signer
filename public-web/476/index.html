1-year rolling coinbase maturity. No cliff.

Under #419, about 6,400 mining rewards all become spendable in one block, 979,920. This pull request gives every reward its own one-year clock instead.

What it does

  • From block 979,920, every reward mined at 973,440 or later waits 52,560 blocks (one year at 144 blocks a day), counted from its own block.
  • Rewards unlock one per block, the first at 1,026,000. The rewards #419 would release together at 979,920 never release together.
  • It reads block heights only, so the year holds whether RDTS is extended or lapses in September 2027.
  • It is a soft fork: it only rejects spends the old rules allowed. Shortening it later would take a hard fork, which is deliberate.
